# Deploying Gaso PWA to Vercel

## Quick Start

### Option 1: Deploy via Vercel Dashboard (Recommended)

1. **Go to Vercel**
   - Visit [vercel.com](https://vercel.com)
   - Sign in with GitHub (or create an account)

2. **Import Your Repository**
   - Click "Add New..." → "Project"
   - Select your `GasWeb` repository
   - Click "Import"

3. **Configure Project Settings**
   - **Framework Preset**: Next.js (auto-detected)
   - **Root Directory**: `./` (default)
   - **Build Command**: `npm run build` (or leave default)
   - **Output Directory**: `.next` (default)
   - **Install Command**: `npm install` (or `yarn install` if using yarn)

4. **Environment Variables**
   Add these in the "Environment Variables" section:
   ```
   GOOGLE_MAP_API_KEY=AIzaSyAJPkU3FuEKHL1qnQy9ZDK671KE33uQSEE
   NEXT_PUBLIC_GOOGLE_MAPS_API_KEY=AIzaSyAJPkU3FuEKHL1qnQy9ZDK671KE33uQSEE
   NEXT_PUBLIC_GOOGLE_MAP_API_KEY=AIzaSyAJPkU3FuEKHL1qnQy9ZDK671KE33uQSEE
   ```
   
   **Important**: Add these for all environments (Production, Preview, Development)

5. **Deploy**
   - Click "Deploy"
   - Wait for build to complete (usually 2-3 minutes)
   - Your app will be live at `your-project.vercel.app`

### Option 2: Deploy via Vercel CLI

1. **Install Vercel CLI**
   ```bash
   npm i -g vercel
   ```

2. **Login to Vercel**
   ```bash
   vercel login
   ```

3. **Deploy**
   ```bash
   vercel
   ```
   
   Follow the prompts:
   - Link to existing project or create new
   - Set up environment variables when prompted

4. **Deploy to Production**
   ```bash
   vercel --prod
   ```

## PWA Considerations

### 1. Service Worker
- ✅ Automatically generated by `next-pwa`
- ✅ Will be available at `/sw.js`
- ✅ Works on HTTPS (Vercel provides HTTPS by default)

### 2. Manifest
- ✅ Located at `/manifest.json`
- ✅ Accessible at `https://your-app.vercel.app/manifest.json`

### 3. Icons
⚠️ **Important**: Make sure you've generated all PWA icons:
- `icon-72x72.png`
- `icon-96x96.png`
- `icon-128x128.png`
- `icon-144x144.png`
- `icon-152x152.png`
- `icon-192x192.png`
- `icon-384x384.png`
- `icon-512x512.png`

If icons are missing, the PWA won't be installable. See `README_PWA.md` for icon generation instructions.

### 4. HTTPS
- ✅ Vercel provides HTTPS by default
- ✅ Required for PWA service workers

## Troubleshooting

### Build Fails

**Error: "Module not found"**
- Check that all dependencies are in `package.json`
- Run `npm install` locally to verify

**Error: "Environment variable not found"**
- Verify all environment variables are set in Vercel dashboard
- Make sure they're added for the correct environment (Production/Preview/Development)

**Error: "PWA service worker not found"**
- Ensure `next-pwa` is properly configured
- Check that build completes successfully
- Verify `public/sw.js` is generated (check build logs)

### PWA Not Installable

1. **Check Manifest**
   - Visit `https://your-app.vercel.app/manifest.json`
   - Verify it's valid JSON
   - Check that all icon paths are correct

2. **Check Icons**
   - Verify all icon files exist in `public` folder
   - Check icon sizes match manifest.json

3. **Check HTTPS**
   - PWA requires HTTPS
   - Vercel provides this automatically

4. **Test with Lighthouse**
   - Open Chrome DevTools → Lighthouse
   - Run PWA audit
   - Fix any issues reported

### Service Worker Not Working

1. **Check Build Logs**
   - Look for `[PWA]` messages in Vercel build logs
   - Verify service worker is generated

2. **Check Browser Console**
   - Open DevTools → Application → Service Workers
   - Verify service worker is registered

3. **Clear Cache**
   - Hard refresh (Ctrl+Shift+R)
   - Clear browser cache

## Continuous Deployment

Vercel automatically deploys:
- ✅ Every push to `main`/`master` branch → Production
- ✅ Every push to other branches → Preview deployment
- ✅ Every pull request → Preview deployment

## Useful Vercel Features

1. **Preview Deployments**: Every branch/PR gets its own URL
2. **Analytics**: Built-in analytics (may require upgrade)
3. **Logs**: Real-time function logs
4. **Edge Functions**: Deploy serverless functions
5. **Image Optimization**: Automatic Next.js Image optimization
