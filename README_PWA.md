## Generating PWA Icons

### Option 1: Using Online Tools (Recommended)

1. **Using PWA Builder Image Generator:**
   - Visit: https://www.pwabuilder.com/imageGenerator
   - Upload your app icon (1024x1024px recommended)
   - Download the generated icons
   - Place them in the `public` folder

2. **Using RealFaviconGenerator:**
   - Visit: https://realfavicongenerator.net/
   - Upload your app icon
   - Configure settings for PWA
   - Download and extract icons to `public` folder

### Option 2: Using Sharp (Programmatic)

1. Install sharp:
   ```bash
   npm install --save-dev sharp
   ```

2. Add your source icon as `public/icon-source.png` (192x192px or larger)

3. Run the icon generation script:
   ```bash
   node scripts/generate-icons.js
   ```

### Required Icon Sizes

The following icons are required (all PNG format):
- `icon-72x72.png`
- `icon-96x96.png`
- `icon-128x128.png`
- `icon-144x144.png`
- `icon-152x152.png`
- `icon-192x192.png`
- `icon-384x384.png`
- `icon-512x512.png`

## Testing PWA

### 1. Build for Production

```bash
npm run build
npm start
```

### 2. Test in Chrome DevTools

1. Open Chrome DevTools (F12)
2. Go to **Application** tab
3. Check:
   - **Manifest**: Should show your manifest.json
   - **Service Workers**: Should show registered service worker
   - **Storage**: Check cache storage

### 3. Test Installability

1. Open the app in Chrome
2. Look for install prompt (or use the install button in address bar)
3. Click "Install" to add to home screen
4. Test the installed app

### 4. Test Offline Functionality

1. Open DevTools → **Network** tab
2. Check "Offline" checkbox
3. Navigate the app - it should work offline
4. Test offline page at `/offline`

### 5. Lighthouse Audit

1. Open Chrome DevTools
2. Go to **Lighthouse** tab
3. Select "Progressive Web App" category
4. Click "Generate report"
5. Should score 90+ for PWA

## PWA Features

✅ **Service Worker**: Automatically generated by next-pwa
- Caches static assets
- Caches API responses (network-first strategy)
- Provides offline functionality

✅ **Manifest**: Configured with:
- App name and description
- Theme colors
- Icons (need to be added)
- Shortcuts for quick actions

✅ **Install Prompt**: Custom component shows when app is installable

✅ **Offline Page**: Available at `/offline` route

✅ **Runtime Caching**: Configured for:
- Google Fonts (cache-first)
- Static assets (stale-while-revalidate)
- API routes (network-first)
- Images (stale-while-revalidate)

## Development vs Production

- **Development**: PWA is disabled (faster builds, easier debugging)
- **Production**: PWA is fully enabled with service worker

To test PWA in development:
1. Set `disable: false` in `next.config.js`
2. Rebuild the app

## Troubleshooting

### Service Worker Not Registering

1. Make sure you're running `npm run build && npm start` (not `npm run dev`)
2. Check browser console for errors
3. Clear browser cache and hard reload

### Icons Not Showing

1. Verify icons exist in `public` folder
2. Check manifest.json has correct paths
3. Clear browser cache
4. Verify icon sizes match manifest

### Install Prompt Not Showing

1. Check manifest.json is valid
2. Verify icons are present
3. Ensure app is served over HTTPS (or localhost)
4. Check browser console for manifest errors
